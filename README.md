## Login demo

Open `index.html` in a browser to preview the responsive sign-in page. The form only checks that both fields are filled in; it does not send or verify credentials. Real authentication requires a server-side implementation and must not store passwords in this static page.

## Partner landing page

Open `partner.html` in a browser to preview the separate NOIR landing page. The login page links to it, and the landing page links back to sign-in. Both pages are static HTML and can be edited directly; no build step is required.

The partner landing page is on the `sanalaiqa79-rg-partner-landing-page` branch, based on `sanalaiqa79-rg-login-page`. To continue working on it, check out that branch or create a new branch from it.
